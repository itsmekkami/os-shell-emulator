# Эмулятор командной оболочки ОС

## Общее описание

Эмулятор командной строки UNIX-подобной ОС с графическим интерфейсом на Python (tkinter). 

Реализован этап 1 - REPL: диалог с пользователем
поддерживается, большинство команд пока заглушки.

Требуется Python 3.9+ с установленным tkinter.

## Структура проекта

- `src/main.py` - точка входа;
- `src/gui.py` - графический интерфейс (окно, ввод, вывод);
- `src/commands.py` - логика команд `ls`, `cd`, `exit`;
- `src/command_parser.py` - разбор строки на команду и аргументы;
- `tests/test_shell.py` - тесты парсера и команд.

## Описание функций и настроек

- Заголовок окна формируется из реальных данных ОС:
  `Эмулятор - [username@hostname]`.
- Парсер учитывает кавычки: `cd "My Documents"` - один аргумент.
- Ошибки (неизвестная команда, неверные аргументы, незакрытая кавычка) выводятся красным цветом.

### Команды:

| Команда | Описание |
|----------------|----------|
| `ls [args...]` | заглушка, выводит имя и аргументы |
| `cd [dir]` | заглушка, выводит имя и аргументы (максимум 1 аргумент) |
| `exit` | завершает работу эмулятора |

### Настройки

- Размер окна: `700×450`.
- Цвет фона: `#1e1e1e` (тёмно-серый).
- Цвет текста: `#d4d4d4` (светло-серый).
- Цвет ошибок: `#f44747` (красный).
- Шрифт: `Courier`, 12 pt.

## Сборка и запуск тестов

**Запуск эмулятора**:

./run.sh        # Linux/macOS

run.bat         # Windows

**Запуск тестов**:

python3 -m unittest discover -s tests -v

## Примеры использования

    user@host$ ls
    ls: аргументы = []
    user@host$ ls -la /home
    ls: аргументы = ['-la', '/home']
    user@host$ cd /tmp

    cd: аргументы = ['/tmp']
    user@host$ cd "My Docs"
    cd: аргументы = ['My Docs']
    user@host$ cd 'My Docs'
    cd: аргументы = ['My Docs']
    
    user@host$ cd a b
    cd: слишком много аргументов
    user@host$ cd "My Docs
    ошибка разбора: No closing quotation
    user@host$$ qwertyu
    qwertyu: команда не найдена

    user@host$ exit
